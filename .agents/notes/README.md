# 决策笔记规范

本文档规范 `.agents/notes/` 下技术决策与踩坑笔记的记录与维护。参考模板：[_template.md](_template.md)。

## 触发条件（满足任一即写）
1. **契约变更**：SQLite schema、索引格式、配置格式、对外 API 契约变更。
2. **跨域影响**：跨两个以上模块或跨仓库的影响。
3. **方案否决**：否决看似更优的方案（必须说明理由与被放弃方案）。
4. **特殊处理**：临时降级、workaround、特判。
5. **上游分歧**：与 upstream 的故意分歧。
6. **性能调优**：性能关键取值的原因与基准。

## 豁免清单
- 仅版本号 bump
- 纯文案调整
- 行为完全不变的单文件 bug 修复
- 小版本依赖升级
- 纯补测试用例

> **注意**：触发优先于豁免。即使是单文件修复，只要涉及 workaround 或特判，必须记录笔记。

## 维护规范
- **命名规范**：`YYYYMMDD-slug.md`（如 `20260917-prefix-diagnostics.md`）。
- **只增不改**：旧笔记废弃时仅修改 frontmatter 中的 `status` 及 `superseded_by` 指针，不重写历史笔记内容。
- **索引更新**：每次新增或修改笔记后，运行 `scripts/notes-index.sh` 刷新本地索引（生成 `INDEX.md`，不入版本控制）。
